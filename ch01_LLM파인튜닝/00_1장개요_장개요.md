# 1장 개요 — LLM Fine-tuning

1장은 사전학습된 LLM 을 가져와 내 문제에 맞게 조정하는 **Fine-tuning** 을 다룬다.
모델을 구하고 실행하는 기반(Hugging Face)에서 시작해, 전체 파라미터를 다시 학습하는
Fine-tuning 을 거쳐, 적은 자원으로 같은 효과를 내는 LoRA 로 나아간다.

**이 장의 구성**

- **1.1 Hugging Face 와 LLM** — 사전학습 모델 플랫폼 Hugging Face 의 사용법.
  계정과 Access Token, Transformers 라이브러리, Pipeline 실습, 동적 양자화,
  ChatBot, Multi-modal 모델.
- **1.2 LLM Fine-tuning** — 사전학습 모델을 새 데이터로 다시 학습시키는 방법.
  Trainer 를 이용한 학습 과정과 한국어 모델 Fine-tuning.
- **1.3 LoRA 를 이용한 Fine-tuning** — 저랭크 어댑터(LoRA)로 파라미터 일부만
  학습하는 효율적 Fine-tuning.
